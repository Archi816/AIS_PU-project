# Два независимых режима RAG

RAG — сначала найти подходящие фрагменты документации, затем передать их языковой модели вместе с проблемой. Модель не читает весь интернет и не скачивает PDF при каждом запросе.

## Выбор режима

Из папки `ai-service`:

```powershell
# Прежние краткие выдержки
.\.venv\Scripts\python.exe -m app.console --retrieval summary

# Полные источники
.\.venv\Scripts\python.exe -m app.console --retrieval full
```

Введите ID устройства и проблему на английском. Флаг действует только на этот запуск.
Для HTTP-сервиса укажите в `.env` `RETRIEVAL_MODE=full` или `RETRIEVAL_MODE=summary` и перезапустите сервер. Если RETRIEVAL_MODE не указан, используется `summary`; в шаблоне .env.example выбран `full` для общей базы команды. Формат POST-запроса не изменился; режим выбирает владелец сервиса, не клиент.

## Что хранится и как работает

| Режим | Данные | Реализация |
|---|---|---|
| summary | Краткие проверенные выдержки в `equipment.documentation_text` | `app/retrieval_summary.py` |
| full | Полный извлечённый текст выбранных источников, разбитый на фрагменты, в `document_chunks` | `app/retrieval_full.py` |

Общие части: `embeddings.py` преобразует текст в числовые векторы для поиска по смыслу; `retrieval.py` загружает только выбранный режим; `model_service.py` отправляет найденный текст модели.

Полный режим:
1. Администратор один раз загружает источники из `data/full_sources.json`.
2. Импортёр извлекает текст всех страниц PDF или всей выбранной статьи. Делит его на фрагменты до 160 слов с перекрытием 30 слов, чтобы не терять связи между соседними частями.
3. Локальная модель BGE вычисляет векторы. Текст, векторы, URL и номера страниц сохраняются в SQL. Отдельный платный embedding API и векторный сервер не нужны.
4. При запросе выбираются фрагменты только для данного ID и модели оборудования. Поиск по смыслу дополняется небольшим бонусом за совпадающие слова; максимум 4 фрагмента передаются языковой модели.
5. Ответ ссылается на `[S1]`, `[S2]` и т.д. Сервер проверяет соответствие ID и возвращает URL из базы, страницу, раздел и исходный фрагмент. Проверка ID не доказывает правильность каждого утверждения — отчёт остаётся предварительным.
6. Если релевантных фрагментов нет или модель их не использовала, `documentation_status=unavailable`; отчёт явно сообщает об общих знаниях и ограничивается общими наблюдениями. Сбой базы/поиска возвращает ошибку, а не скрывается под таким ответом.

`retrieval_mode` в ответе показывает фактический режим. В full-источниках `retrieved_at` — дата индексации скачанного текста, а не дата проверки техником; `verified_at` пустой. У PDF `page` — номер страницы файла, иногда отличается от печатной нумерации.

## Источники и ограничения

| ID | Полный выбранный источник |
|---|---|
| PC-001 | Dell OptiPlex 7090 Micro Service Manual, 64 страницы; документ Dell на зеркале дистрибьютора |
| LAP-001 | HP ProBook 450 G8 Maintenance and Service Guide, 95 страниц |
| PRN-001 | Полная статья Creality о пропусках подачи экструдера |
| ROB-001 | Полная страница ROBOTIS TurtleBot3 Bringup, несколько версий ROS |
| ARD-001 | Arduino UNO R3 User Manual A000066, 14 страниц |
| RPI-001 | Raspberry Pi 4 Model B Datasheet, 13 страниц |
| MUL-001 | Fluke 110/113/114/115/117 User Manual, 22 страницы; нужны инструкции именно для 115 |

Все URL находятся в `data/full_sources.json`. Это полные **выбранные документы**, а не вся документация производителя: например, руководство Arduino не заменяет все статьи об ошибках avrdude. Можно добавлять несколько источников одному устройству.

Изображения, схемы и сканы без текстового слоя не распознаются. Таблицы PDF могут извлекаться с потерей расположения столбцов. Совпадения по смыслу не гарантируют верный диагноз. Начальный порог 0.48 нужно оценивать на реальных случаях; это не вероятность правильности ответа. Для семи устройств перебор векторов прост и достаточен; при большом каталоге стоит перейти на индекс pgvector.

## Обновление индекса

```powershell
# Зависимости (включая чтение PDF/HTML)
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
# На новом компьютере скачать локальную поисковую модель
.\.venv\Scripts\python.exe -m app.retrieval
# Явно использовать отдельный файл владельца БД
.\.venv\Scripts\python.exe -m app.index_documents --admin-env .env.admin
# Повторно скачать источник одного устройства
.\.venv\Scripts\python.exe -m app.index_documents --admin-env .env.admin --equipment ARD-001 --refresh
```

`.env.admin` содержит только DATABASE_URL владельца и не передаётся коллегам/в Git. Обычный `.env` остаётся с пользователем `lems_reader`, имеющим только чтение. Если используется локальная SQLite, флаг `--admin-env` не нужен, каталог должен быть предварительно создан.

Обычный запуск импортёра использует `data/document-cache`, `--refresh` загружает заново. Неизменившиеся документы повторно не индексируются. При ошибке предыдущие фрагменты данного источника сохраняются. Удаление записи из JSON само по себе не удаляет старые фрагменты: удалите их отдельно из `document_chunks` по точному `equipment_id` и `url` через SQL Editor. Таблицу equipment импортёр не изменяет.

Для нового HTML-источника задайте CSS-selector контейнера статьи (например `article`), чтобы меню сайта не попадало в поиск. Это ручной список доверенных публичных источников; API не принимает произвольные ссылки от пользователей. Не добавляйте секретные адреса или внутренние сетевые ресурсы. Если сайт блокирует загрузку, импорт завершается ошибкой, а не сохраняет страницу блокировки.

## Независимое удаление

Сначала переключите `.env` на оставляемый режим и перезапустите сервис.
- Оставить summary: можно удалить `app/retrieval_full.py`, `app/index_documents.py`, `data/full_sources.json` и кеш `data/document-cache`. Отдельная таблица document_chunks больше не используется; её удаление необязательно. Зависимости beautifulsoup4/pypdf/fonttools нужны только импортёру.
- Оставить full: можно удалить `app/retrieval_summary.py`. Поля старых выдержек в equipment можно оставить: full их не использует. Не удаляйте сам каталог оборудования.

Общие `retrieval.py`, `embeddings.py`, каталог, конфигурация и сервис нужны обоим вариантам. Автоматического переключения на другой режим или платную модель нет.
